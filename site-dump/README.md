# 站点内容抓取：2026年"天翼AI"杯重庆高校人工智能大赛官网

对 `http://aiac.cqut.edu.cn:3090/` 的公开内容抓取存档（作业用）。

- **[report.md](./report.md)** ← 先看这个：站点概览、页面结构、大赛核心信息、接口分析、观察发现
- **[content/](./content/)** ← 公告 / 参赛指南 / 新闻全文（Markdown）+ 资料清单 + 学院清单
- **api/** ← 所有接口的原始 JSON 响应（列表、详情、配置）
- **chunks/** ← 前端 49 个 JS chunk（Nuxt 3 打包产物）
- **assets/** ← 下载的图片 / PDF / DOCX / 视频，清单见 `assets/_manifest.json`
- **crawl.log** ← 抓取日志（每次请求的记录）

## 一句话结论

这是重庆理工大学联合中国电信重庆分公司举办的校级 AI 竞赛平台
（Nuxt 3 前端 + likeadmin 后端，后端版本 1.9.4），大赛主题"智创校园·赋能未来"，
作品须基于学校"智小理"智能体平台开发，设管理服务/教学赋能/科研赋能/其它创意四大赛道。

## 抓取范围与合规

- 仅公开只读接口（HTTP GET），限速 0.35~0.4 秒/请求
- 未登录、未调用任何写接口（登录/短信/报名/提交/上传一律未触碰）
- 站点 `robots.txt` 为 `User-agent: *` + 空 `Disallow`，允许全站抓取
