# 提交材料存放目录

把要提交的材料**按下面的命名规则**放在本目录，然后运行：

```bash
./tools/pack-submission.sh "队长姓名" "联系方式"
```

脚本会自动检查必需材料是否齐全，并打包成 `提交包-<队长姓名><联系方式>.zip`。

## 命名规则（脚本靠文件名识别）

| 材料 | 命名规则 | 数量要求 | 是否必需 |
| --- | --- | --- | --- |
| 作品提交表 | `作品提交表-职引.pdf`（或多份：`作品提交表-终版.pdf`） | 1 份 | ✅ 必需 |
| 作品演示视频 | `作品演示视频.mp4` | 1 个，**< 3:00** | ✅ 必需 |
| 团队活动记录·图片 | `团队活动-01.jpg`、`团队活动-02.jpg` … | **≥ 3 张** | ✅ 必需 |
| 团队活动记录·视频 | `团队活动记录.mp4` | ≥ 30 秒 | ⚠️ 官方要求，建议补 |
| 作品截图 | `作品截图-01.png` … | 3–5 张 | 建议 |
| 其他（工作流编排图、监测数据图等） | 任意 `*.png` / `*.jpg` | — | 可选 |

## 各材料的来源

| 材料 | 怎么产出 |
| --- | --- |
| 作品提交表 PDF | ✅ 已生成 `作品提交表-职引.pdf`（7 页）。改动文案后重出：先改 `02-提交材料清单.md` 的草稿 A/B/C，再跑 `python 技术档案/gen_submission_form.py`，然后用 Word 导出 PDF |

> ⚠️ 本目录内容**不会被 git 提交**（见仓库根 `.gitignore`），避免大文件与个人信息进仓库。

| 口令文件 | `F:\zcode\suiyi\提交材料口令-20261020.txt`（仓库外，**不要提交、不要截图外发**） |

还原（在仓库根 `F:\zcode\suiyi\ggg` 执行）：

```bash
python 参赛方案/tools/submission-archive.py unpack \
  --archive F:\zcode\suiyi\职引-提交材料-20261020.tar.gz.enc \
  --password-file F:\zcode\suiyi\提交材料口令-20261020.txt \
  --dest D:\restore
```

重新打包（材料改动后）：

```bash
python 参赛方案/tools/submission-archive.py pack \
  --password-file F:\zcode\suiyi\提交材料口令-20261020.txt
```

> 口令丢失 = 归档不可恢复（无后门无托管）。归档带 GCM 认证标签，被改动会直接报"解密失败"，不会静默还原出坏数据。
