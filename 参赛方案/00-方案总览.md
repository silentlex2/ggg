## 一、为什么选这个方向（决策依据）

官方《选题参考方向》给出三条实战建议：**① 小而专 ② 数据与权限先行 ③ 突出"有用+可评估"**。
用这四条判据筛掉其他方向：

| 判据 | 「职引」 | 课程 AI 助教（最热门） | 新生报到向导 | 报修助手 |
| --- | --- | --- | --- | --- |
| **可演示性**（3 分钟出效果） | ★★★★★ 上传简历立刻出报告 | ★★★ | ★★★ | ★★★ |
| **技术复杂度**（不像套壳） | ★★★★★ 全平台能力都用上 | ★★★ | ★★ | ★★★ |
| **数据可得**（不需内网） | ★★★★★ 岗位/题库自行构建 | ★★★★ | ★★★ | ★★ 需后勤系统 |
| **价值可量化** | ★★★★★ 诊断耗时/匹配度/满意度 | ★★★ | ★★ | ★★★ |
| **竞争烈度** | 低（★★★ 难度劝退） | **极高** | 高 | 中 |

**核心判断**：就业服务是"评委自己也有共鸣"的场景（人人找过工作），
而它正好能把智小理平台的**文档提取、数据库 NL2SQL、多智能体、长期记忆**这些高阶能力全用上——
这是拉开与技术套壳作品差距的关键。

## 二、一句话定位

> **「职引」把就业指导中心"一对一辅导"这件事，做成 7×24 小时可用的智能体：
> 上传一份简历 → 得到针对性诊断 → 匹配到适合自己的校内岗位 → 对着目标岗位做一场模拟面试 → 拿到复盘报告。**

**差异化（为什么通用大模型替代不了）**：

1. **懂重理工**：知道本校有哪些专业、哪些企业来校招、往届师兄师姐去了哪
2. **懂岗位**：匹配基于**校内真实岗位库**（结构化数据库），不是泛泛而谈
3. **闭环**：诊断 → 匹配 → 陪练 → 复盘，形成成长轨迹（长期记忆）
4. **有出处**：每条建议都标注知识库来源，可追溯、可复核

## 三、痛点与可量化价值

| 痛点（真实存在） | 「职引」怎么做 | 可量化指标 |
| --- | --- | --- |
| 就业老师一对一辅导成本高，1 位老师面对数千学生 | 7×24 自助诊断与陪练 | 单次辅导从 **30 分钟 → 3 分钟**，承载力提升 10 倍 |
| 学生简历千篇一律，不会按岗位 JD 改 | 对照目标岗位逐条诊断 | 简历匹配度评分 + 5 条具体改法 |
| 不知道哪些企业招自己专业 | 基于专业-行业-岗位库匹配 | 输出 Top 10 岗位 + 匹配理由 |
| 面试没练过，临场紧张 | 多智能体模拟面试 + 追问 | 人均可练 **20+ 场**，覆盖 8 类高频问题 |
| 改完不知道有没有进步 | 长期记忆记录每次表现 | 生成"改进轨迹"，能力项可视对比 |

## 四、目标用户

- **主用户**：大三、大四准备求职/实习的学生（重理工在读）
- **次用户**：就业指导中心老师（用智能体做团体辅导、统一答复口径）
- **使用方式**：扫码打开前端页面即用，无需登录、无需安装

## 五、功能模块（三大功能 + 1 个加分项）

### 模块 1 · 简历诊断（入口级功能，演示主力）

```
用户上传简历(PDF/Word) → 文档提取 → 代码节点结构化 → 选择目标岗位
   → 大模型对照岗位JD逐条诊断 → 输出「诊断报告」
```

**输出示例**（结构化、美观、可截图）：

```
📊 简历诊断报告 · 目标岗位：软件开发工程师（Java）

综合匹配度  ███████░░░  72 / 100

【分项得分】
项目经历    ████████░░  80   有 2 段实习，但缺少量化结果
技能匹配    ██████░░░░  60   岗位要求 Redis/消息队列，简历未体现
表达规范    ████████░░  78   建议项目描述用 STAR 结构
排版格式    █████████░  90   格式规范，无硬伤

【优先改进 3 条】
1. 项目经历加量化：「优化接口性能」→「接口响应从 800ms 降至 120ms」
2. 补充岗位关键词：Redis、消息队列（JD 中出现 5 次，简历 0 次）
3. 教育背景补充：相关课程与 GPA 排名

📚 依据：校内《软件开发工程师岗位JD库》第 12 条、《简历写作规范》第 3 章
```

### 模块 2 · 岗位匹配（展示数据库能力）

```
用户说「我是计算机学院大三，会 Java 和 MySQL，想找重庆的实习」
   → 问题分类 → 大模型抽取结构化条件（专业/技能/城市/类型）
   → 数据库节点（自然语言转 SQL）查询校内岗位库
   → 大模型排序 + 生成匹配理由 → 输出岗位卡片列表
```

**技术亮点**：这是**结构化数据 + 大模型**的组合，不是纯 RAG 问答——
用上平台的**数据库节点（NL2SQL）**，评委能直观看到"智能体真的在查数据"。

### 模块 3 · 面试陪练（复杂度最高，差异化最强）

**多智能体协同**设计：

| 角色 | 职责 |
| --- | --- |
| 🎤 面试官 Agent | 按目标岗位出题、追问、控制节奏 |
| 🧐 评估 Agent | 实时观察回答，从逻辑性/专业度/表达三维打分 |
| 🧭 复盘 Agent | 结束后汇总成报告，给改进建议 |

```
选择岗位 → 面试官出题(结构化题库) → 用户作答
   → 面试官追问(最多3轮) → 下一题 ... (共 5 题)
   → 评估 Agent 汇总 → 复盘报告 + 能力对比
```

**输出示例**：

```
🎯 模拟面试复盘 · 软件开发工程师

本次得分  ███████░░░  74 / 100

逻辑性 ████████░░ 80   回答有结构，但结论前置不够
专业度 ██████░░░░ 62   第 3 题「索引优化」回答偏浅
表达   █████████░ 85   语速适中，术语使用准确

💡 待加强：数据库索引与事务隔离级别
🔁 建议再练：第 3 题（已加入你的训练计划）
```

### 模块 4 · 政策咨询（实时数据源 + 官方文号，路演加分项）

- 政策分流在检索本地政策库**之前**，先由 **HTTP 请求节点**实时拉取「国家大学生就业服务平台」（教育部主管，www.ncss.cn）公开接口的政策动态
- 覆盖三方协议、档案、报到证、劳动合同、试用期、社保、应届生身份、基层就业项目、就业补贴等高频问题
- 补贴类答复**精确到重庆市官方文号**（渝财规〔2026〕3 号 / 渝人社〔2024〕242 号 / 渝人社规〔2026〕12 号 / 渝人社规〔2025〕3 号）

> 这个模块是**路演加分项**：它证明作品的回答不是静态知识，而是**带着"今天的政策"在答**。
> HTTP 节点实测 20/20 稳定（见 `运行状态与待办.md`）。

> ⚠️ **口径统一（单人参赛版）**：对外统一表述为 **"三大功能 + 一个加分项"**：
> 必做 = 简历诊断 / 岗位匹配 / 模拟面试；加分项 = **政策咨询**。
> ⚠️ **不要再提"成长档案"**——它依赖长期记忆，而平台长期记忆后端不完整、已主动降级为单会话内记忆。
> 提交材料、路演、答辩一律按上面这个口径，避免初审与答辩对不上。

| 节点 | 实测 | 降级方案 |

> 演示和真实使用都不能卡死，所以最终形态只保留稳定节点。

## 八、美观与易用性设计

### 8.1 第一印象（打开即惊艳）

- **开场白**：「你好，我是职引 👋 把简历发给我，我帮你看看哪里能改；或者直接告诉我你想找什么工作。」
- **预置问题**（平台支持，点击即用）：
  - 📄 帮我诊断简历
  - 🔍 帮我匹配岗位
  - 🎤 来一场模拟面试
  - 📋 三方协议怎么签

### 8.2 输出美观（关键！评委看的是截图和 3 分钟演示）

| 手法 | 说明 |
| --- | --- |
| **进度条可视化** | 用 `███████░░░ 72/100` 代替干巴巴的"72 分"，一眼看出强弱项 |
| **分区卡片** | 📊 诊断报告 / 🎯 复盘报告 / 🔍 岗位卡片，用 emoji + 分隔线分区 |
| **优先级排序** | 改进建议永远按"影响最大"排序，不说废话 |
| **引用归属** | 每条结论后面标 `📚 依据：xxx`，点击可溯源 |
| **表格化对比** | 岗位匹配结果用表格：岗位 / 企业 / 匹配度 / 关键理由 |

### 8.3 易用性（零学习成本）

- **扫码即用**：发布到「前端页面」渠道，生成 URL + 二维码，无需注册登录
- **一条龙**：上传简历后自动进入诊断流程，不用先选菜单
- **多轮引导**：每一步结束后主动给 2–3 个下一步选项
- **容错**：识别不出目标岗位时，主动追问而不是瞎猜

### 8.4 会话背景与品牌

- 设置会话背景图（平台支持），配一个简洁的「职引」LOGO
- 统一话术风格：专业但不生硬，像一个耐心的学长

## 十一、风险与对策

| 风险 | 对策 |
| --- | --- |
| 平台能力与预期不符（如数据库节点受限） | **P1 阶段先做最小验证**，跑不通就把"岗位匹配"降级为知识库检索，不影响主线 |
| 岗位数据不足 | 先用校内招聘会公开信息 + 手工整理 30–50 条跑通，后期再扩 |
| 简历涉及隐私 | 只存结构化结果不存原文；材料中明确说明；答辩主动讲 |
| 4 周做不完 | 优先级：简历诊断 > 面试陪练 > 岗位匹配 > 政策咨询 |
| 初审被刷 | 材料重点写"技术实现"（用了哪些节点、怎么防幻觉），这是专家最想看的 |
| 路演超时 | 提前排练到 **4 分 30 秒**，留缓冲 |
