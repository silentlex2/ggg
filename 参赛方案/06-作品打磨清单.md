## 六、平台最小验证清单（**先做这个，再决定作品形态**）

> 配套回归测试用例（意图 12 条 / 岗位 10 条 / 异常 8 条 / 面试全流程 / 记忆 / 视觉）与试用数据记录表见 `08-测试与验收.md`。

| # | 验证项 | 通过标准 | 不通过时的降级路径 |
| --- | --- | --- | --- |
| 1 | 创建工作流应用 | 能进入编排画布 | — |
| 2 | 文档提取节点（PDF/DOCX） | 能返回文本，中文不乱码 | 提示用户换格式；知识库开"精准解析" |
| 3 | 代码节点（Python） | 能 import json/re，能返回 dict | 改用大模型节点兜底 |
| 4 | 问题分类节点 | 4 类各测 3 条，准确率可接受 | 用大模型节点 + 条件节点自建分类 |
| 5 | **数据库节点（NL2SQL）** | 能连上岗位库并返回行 | **降级为知识库版岗位匹配（KB4 md）** |
| 6 | **长期记忆写入/读取** | 跨会话能读到上次记录 | 🔴 实测后端不完整 → **成长档案砍掉**，改用政策咨询当加分项 |
| 7 | 知识库（非结构化） | 召回相关片段，能显示引用 | 调整分段/相似度阈值 |
| 8 | 知识库（问答对） | 命中即秒答 | 改用非结构化 + 提示词约束 |
| 9 | 会话变量 | 跨轮不丢状态 | 用记忆节点替代 |
| 10 | 模板转换（Jinja2） | 能拼出统一输出 | 用代码节点拼字符串 |

**实测结论（2026-10-14，每项跑 20–32 次）**：

| 节点 | 实测成功率 | 结论 |
| --- | --- | --- |
| 代码节点（Python） | 24/32 ≈ **75%** | 🔴 不可用，已移除 |
| 模板转换（Jinja2） | 21/26 ≈ **81%** | 🔴 不可用，已移除 |
| HTTP 请求节点 | **20/20** | ✅ 可用，已用于政策实时源 |
| 参数提取节点 | **15/15** | ✅ 可用，已用 9 处 |
| 重排模型 `bge-reranker-v2-m3` | 岗位库启用后全流程无失败节点 | ✅ 可用，v4 站点已启用 |
| 数据库节点 | 连接超时 | 🔴 不可用，岗位匹配改走知识库 |
| 长期记忆 | 后端不完整 | 🔴 未启用，降级为单会话记忆 |

> **结论**：最终形态只保留 HTTP / 大模型 / 参数提取 / 知识库检索 / 分类 / 条件 / 文档提取这几类节点。
