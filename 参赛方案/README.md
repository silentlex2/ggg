## 四条最重要的提醒

1. **10/20 报名截止**（自主命题需审核），**11/10 18:00 提交截止**
2. **线上初审只决定能否进前 30，最终成绩 100% 来自线下 5 分钟路演 + 3 分钟答辩**
3. 作品必须基于学校"智小理"平台开发，**不能连校园内网系统** —— 本方案的功能模块都不依赖内网
4. **口径按单人参赛版**：必做 = 简历诊断 / 岗位匹配 / 模拟面试**三大功能**，
   成长档案是**加分项**（时间不够可砍）。平台能力统一说 **16 项（8 项高阶）**，答辩亮点 **13 条**
