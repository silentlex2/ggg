# 单人参赛调整 · 报名指南

> 结论先说：**比赛不要求作品与所学专业相关**，方案不用因为「化学工程与工艺」而改；
> 但**单人参赛**必须调整范围，见第三节。

---

## 一、有没有专业限制？—— 没有

我逐份查了官方文件，三条依据：

**依据 1：官方通知与指南全文，检索「专业」→ 出现 0 次**

对公告 1（官方全文）、公告 6、公告 7、5 份参赛指南做全文检索：

| 关键词 | 出现次数 |
| --- | --- |
| 专业 | **0** |
| 学院 | 仅出现在"校属各单位，各学院""承办单位：计算机科学与工程学院"等**组织单位**表述中 |

参赛资格只写了一条：**"重庆理工大学在读学生（含本科生、研究生、留学生）"**——按**学校**限定，不按专业限定。

**依据 2：报名表单里根本没有「专业」这个字段**

从报名页前端代码提取到的完整字段清单：

| 分区 | 字段 |
| --- | --- |
| — | 学院名称 |
| — | 队伍名称（20 字内） |
| **队长信息** | 姓名 / 学院 / 学号 / 手机号 |
| 成员信息 | 姓名 / 学院 / 学号 / 手机号（按人数） |
| **指导老师（选填）** | 姓名 / 教工号 / 手机号 |
| 作品信息 | 参赛作品方向（四选一赛道）/ 参赛作品名称（20 字内）/ 课题选择（指定命题时） |

**只有「学院」，没有「专业」**——报名环节就不采集专业，自然不可能据此评判。

**依据 3：赛道按「应用场景」划分，不按学科划分**

| 赛道 | 官方定义 |
| --- | --- |
| 管理服务智能体 | 校园办事、智能迎新/毕业、设施预约等 |
| 教学赋能智能体 | AI 课程助教、作业批改等 |
| 科研赋能智能体 | 科研文献分析、数据分析、实验设计优化等 |
| 其它创意智能体 | 多模态交互、个性化陪伴等 |

官方《选题参考方向》里的 16 个场景，全部按**业务部门**（教务处、学工部、后勤、就业中心…）归类，
与参赛者本人的专业无关。

## 二、单人参赛可以吗？—— 明确可以

官方通知第二条原文：

> 组队人数：每支队伍 1—4 人，须指定 1 人为队长……**单人独立参赛亦可**，可自愿选填指导教师。

报名表里也印证了：指导教师标注为**「选填」**。

> ✅ 所以：**1 人 + 无指导教师，完全符合规则。**

## 三、单人版必须砍范围（这才是真正要改的地方）

原方案按 3 人分工设计（1 人工作流 / 1 人知识库 / 1 人文档与视频）。
**单人 4 周，产能约为原方案的三分之一**，必须做减法。

### 3.1 功能优先级（按"性价比"排序）

| 优先级 | 模块 | 为什么这个顺序 | 单人可行性 |
| --- | --- | --- | --- |
| **P0 必做** | 📄 **简历诊断** | 演示主力，3 秒出报告，视觉冲击最强；数据（写作规范）可公开搜集 | ✅ 约 5 天 |
| **P0 必做** | 🎤 **模拟面试** | 差异化核心，"多智能体"是技术亮点；题库可公开整理 | ✅ 约 5 天 |
| **P1 争取** | 🔍 **岗位匹配** | 展示数据库能力，但**要手工整理岗位库**，最耗时 | ⚠️ 约 6 天 |
| **P2 砍掉** | 📈 成长档案 | 锦上添花，不影响主线 | ❌ 时间不够就不做 |

### 3.2 岗位匹配的"降级方案"（重要）

原方案要用**数据库节点（自然语言转 SQL）**——这是最亮的技术点，但要建结构化岗位库。

**单人建议这样处理**：

1. **先做知识库版**（2 天）：把 30–50 条岗位信息整理成文档喂进知识库，
   用「知识库检索 + 大模型排序」实现匹配——**能跑通、能演示**
2. **如果 P0 提前完成**，再升级为数据库节点版（NL2SQL）

> 这样保证：**最坏情况下也有 3 个模块能演示，最好情况有 4 个且带数据库亮点。**

### 3.3 单人版排期（重排）

| 时间 | 任务 | 里程碑 |

## 四、借专业优势的两个小设计（不改方向，只做加分）

不换方向，但可以把自己的专业变成**细节优势**：

### 4.1 把自己的专业做成"样板专业"

知识库 KB3（专业-行业-岗位对照）里，**把"化学工程与工艺"这一条做深做透**：

- 对应行业：化工、新材料、新能源、制药、环保、食品
- 典型岗位：工艺工程师、研发工程师、质检、生产管理、EHS 工程师
- 本地企业：重庆及周边的化工/材料类企业（长寿化工园区、万华、巴斯夫重庆等）
- 往届去向：结合学校就业质量报告

**好处**：路演时用**自己的专业**做演示——数据最熟、讲得最真、评委能感到"这是真做过的"。
其他专业保持通用即可。

### 4.2 加一个"专业适配度"视角

简历诊断时，除通用维度外，增加一条**「专业-岗位适配度」**判断：
"你的专业是化学工程与工艺，目标岗位是工艺工程师——**专业对口度高**，
建议重点补充：化工原理/反应工程相关项目经历、Aspen Plus 等过程模拟工具。"

> 这一条让作品有了**别人抄不走的细节**，也让你的化工背景变成了资产而不是负担。

## 五、为什么不建议换成化工方向的选题

你可能会想：既然我是化工专业，是不是做个"化工文献/实验助手"更占优？我对比后**不建议**，三个理由：

| 理由 | 说明 |
| --- | --- |
| **评委构成** | 主办是信息中心 + 电信，承办是**计算机科学与工程学院**，技术支持含**两江人工智能学院** + 电信 AI 中心——评委大概率是**计算机/AI 背景**。通用场景他们能判断技术含量；化工专业价值他们反而难评估 |
| **评审侧重** | 管理服务赛道明确要求"**具备推广条件**"。化工专用工具受众窄，天然吃亏 |
| **沉没成本** | 方案已完整设计，换方向等于白扔一周，而单人最缺的就是时间 |

> 换句话说：**你的专业是加分项，但没必要成为选题的限制。**
