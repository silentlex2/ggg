# 「职引」交互原型

**`职引-交互原型.html`** —— 单文件交互原型，双击用浏览器打开即可（无需服务器、无需联网）。

> ⚠️ **重要说明**：这是**设计原型**（纯前端模拟，数据为示例数据），
> 用于展示功能的界面效果与交互流程。**不能**当作真实作品截图提交，
> 提交材料里的截图必须来自智小理平台上的真实运行界面。

## 能演示什么（v2，9 个场景）

| 点击 / 输入 | 看到的效果 |
| --- | --- |
| 📄 帮我诊断简历 | 诊断报告：**一句话结论** + 综合匹配度 + 四条分项进度条（带颜色分级）+ 三条改进建议 + 专业适配度 + 引用来源 |
| 🔍 帮我匹配岗位 | **岗位表格**（4 列，移动端不溢出）：岗位 / 匹配度 + 档位标签 / 关键匹配理由，下方给前 2 名差距提示 |
| 回复 `1`–`4` | **岗位详情下钻**：硬性要求 + "你需要在简历里体现" + 薪资 + 数据更新日期 |
| 回复 `6`（越界） | **异常兜底演示**：友好提示"本次共 4 个岗位" |
| 🎤 来一场模拟面试 | 面试官开场白（含规则说明与第 1 题） |
| 🔁 重练第 3 题 | **重练分支**：上次回顾（原话 + 得分 + 问题）+ 原题重述 |
| 📈 我的进步 | **成长档案**：四维得分与上次对比（▲/▼）+ 进步最大项 + 需保持注意项 |
| 📋 三方协议怎么签？ | 政策回答：结论 → 要点 → 怎么做 → 引用来源 + 免责提示 |
| 输入"食堂几点开门" | **库外问题拒答**：明确说没有权威依据，不编造 |

> 输入框里输入以下关键词也会触发对应场景：
> `简历` / `岗位` / `面试` / `三方` / `档案` / `试用期` / `重练` / `进步` / `食堂` 等。

## 与平台输出的一致性（v2 已对齐）

原型现在与 `04`/`05` 的平台输出规范**逐项一致**，可作为开发时的界面参照：

| 规范 | 原型中的体现 |
| --- | --- |
| 一句话结论前置 | 诊断 / 岗位 / 复盘 / 进步四处都有结论块 |
| 进度条双保险 | 彩色进度条 + 分数 + 档位标签（优秀/良好/待改进） |
| 表格化（≤5 列） | 岗位匹配改为 4 列表格 |
| 统一 emoji 分区 | 📊 诊断 / 🔍 岗位 / 🎯 复盘 / 📋 政策 / 📈 进步 |
| 引用归属 | 每份报告底部 `📚 依据：…` |
| 多轮闭环 | 岗位编号下钻、重练第 N 题 |
| 异常兜底 | 越界编号、库外问题均有对应话术 |

## 设计要点（可写进提交表的"美观性"部分）

1. **进度条可视化**：带颜色分级的进度条代替纯数字（≥80 绿 / 60-79 橙 / <60 红），并配文字档位
2. **信息分层**：一句话结论 → 分项数据 → 改进建议 → 依据来源
3. **表格化岗位展示**：4 列压缩到手机宽度，信息密度高但不横向滚动
4. **引用归属**：每条回答底部标注知识库来源，强化可信度
5. **移动优先**：手机端全屏适配，契合"扫码即用"的使用场景
6. **品牌色**：青蓝渐变（`#0ea5a4 → #2563eb`），与 `素材/职引-LOGO.svg`、会话背景图同一套视觉

## 怎么用

- **路演时**：可作为"设计理念"的辅助展示（**必须说明是原型**）
- **开发时**：作为界面参照，把对应的排版方式在智小理平台里复现
- **答辩时**：讲"我们做了信息分层设计，让评委和用户 3 秒看懂结论"

## 已知限制

- 面试场景只到**开场白**，没有实现 5 题完整流程与复盘（复盘报告是独立的静态示例，可通过"重练"和"我的进步"看到后续环节的样子）
- 岗位库为 4 条示例数据，与 `KB4` 的 65 条无关
- 无后端、无真实推理，所有回复都是预设文本
