# 「职引」交互原型

**`职引-交互原型.html`** —— 单文件交互原型，双击用浏览器打开即可。

> ⚠️ **重要说明**：这是**设计原型**（纯前端模拟，数据为示例数据），
> 用于展示四个功能的界面效果与交互流程。**不能**当作真实作品截图提交，
> 提交材料里的截图必须来自智小理平台上的真实运行界面。

## 能演示什么

| 点击按钮 | 看到的效果 |
| --- | --- |
| 📄 帮我诊断简历 | 简历诊断报告：综合匹配度大数字 + 四条分项进度条（带颜色分级）+ 三条优先改进建议 + 专业适配度 + 引用来源 |
| 🔍 帮我匹配岗位 | 四张岗位卡片：岗位名 / 企业类型 / 城市 / 薪资 + 匹配度分数 + 匹配理由 + 差距提示 |
| 🎤 来一场模拟面试 | 面试官开场白（含规则说明与第 1 题） |
| 📋 三方协议怎么签？ | 政策回答：结论 → 要点 → 怎么做 → 引用来源 + 免责提示 |

## 设计要点（可写进提交表的"美观性"部分）

1. **进度条可视化**：用带颜色分级的进度条代替纯数字（≥80 绿 / 60-79 橙 / <60 红）
2. **信息分层**：结论前置 → 分项数据 → 改进建议 → 依据来源
3. **卡片式岗位展示**：每张卡片包含"匹配理由 + 差距提示"，信息密度高但不乱
4. **引用归属**：每条回答底部标注知识库来源，强化可信度
5. **移动优先**：手机端全屏适配，契合"扫码即用"的使用场景
6. **品牌色**：青蓝渐变（#0ea5a4 → #2563eb），专业但不冰冷

## 怎么用

- **路演时**：可作为"设计理念"的辅助展示（明确说明是原型）
- **开发时**：作为界面参照，把对应的排版方式在智小理平台里复现
- **答辩时**：讲"我们做了信息分层设计，让评委和用户 3 秒看懂结论"
