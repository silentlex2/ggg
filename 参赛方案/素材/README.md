## 二、怎么用

1. **应用头像**：上传 `职引-LOGO-512.png`。
   （PNG 版是纯图形标记——罗盘 + 向上箭头，无文字，更适合小尺寸头像；
   需要带「职引」二字的版本，用浏览器打开 `职引-LOGO.svg` 后另存为图片。）
2. **会话背景**：上传 `职引-背景-1200x900.png`。浅色低对比，不抢正文。
3. **演示简历**：把 `演示简历样本-化工工艺工程师.md` 复制到 Word 里排版，
   另存为 PDF，命名 `张明-化工工艺工程师-重庆理工大学.pdf`。
4. **重新生成 PNG**（改配色或尺寸时）：

```bash
python3 make-png.py     # 约 25 秒，输出两个 PNG 到本目录
```

> 沙箱里没有 PIL / rsvg / inkscape，所以 `make-png.py` 用 `zlib` 手写像素渲染
> （超采样抗锯齿）。换电脑后如果装了 ImageMagick，也可以直接
> `magick -background none 职引-LOGO.svg -resize 512x512 职引-LOGO-512.png`。

## 三、配色规范（全站统一）

| 用途 | 色值 |
| --- | --- |
| 主色（青） | `#0ea5a4` |
| 主色（蓝） | `#2563eb` |
| 渐变 | `linear-gradient(135deg, #0ea5a4 0%, #2563eb 100%)` |
| 分数档位色 | ≥85 绿 `#10b981` ｜ 70–84 橙 `#f59e0b` ｜ <70 红 `#ef4444` |

> 这三个色值与 `原型/职引-交互原型.html` 完全一致——原型、LOGO、背景图、
> 平台输出必须**同一套视觉**，否则评委会觉得"拼凑感"。

## 四、演示简历样本的用法

`演示简历样本-化工工艺工程师.md` 里**故意留了 6 处典型硬伤**（无量化结果、
通篇"负责/参与"、无求职意向、空泛自我评价、岗位关键词缺失、无 GPA），
演示时"诊断 → 改进"的效果最明显。

**预期诊断结果**：综合匹配度落在 60–72 分，技能匹配为最低项，
改进建议应命中「补量化结果」「改强动词」「补 HAZOP/PID 关键词」。

> ⚠️ 文件末尾那张"6 处硬伤"对照表是**给你自查用的**，
> 录屏时不要滚到那里，以免穿帮。
