# 「职引」素材库

> 建应用时就要用到的素材。**均为原创或虚构，可安全用于演示与提交。**

| 文件 | 用途 | 怎么用 |
| --- | --- | --- |
| `职引-LOGO.svg` | 应用头像 / 路演封面 / 二维码中心 | 上传前导出为 PNG（512×512）；若平台不接受 SVG，用浏览器打开后截图或转 PNG |
| `职引-会话背景.svg` | 前端页面「会话背景图」 | 导出 PNG（1200×900）；浅色低对比，不抢正文 |
| `演示简历样本-化工工艺工程师.md` | 路演/录屏时上传的简历 | **先导出为 PDF**，命名 `张明-化工工艺工程师-重庆理工大学.pdf` |
| `数据合规与隐私说明.md` | 答辩必问题 + 提交表"技术实现"节 | 直接摘抄，**同时要保证实现与之一致** |

## 配色规范（全站统一）

| 用途 | 色值 |
| --- | --- |
| 主色（青） | `#0ea5a4` |
| 主色（蓝） | `#2563eb` |
| 渐变 | `linear-gradient(135deg, #0ea5a4 0%, #2563eb 100%)` |
| 分数档位色 | ≥85 绿 `#10b981` ｜ 70–84 橙 `#f59e0b` ｜ <70 红 `#ef4444` |

> 这三个色值与 `原型/职引-交互原型.html` 完全一致——原型、LOGO、背景图、
> 平台输出必须**同一套视觉**，否则评委会觉得"拼凑感"。

## 转 PNG 的快捷方法

```bash
# 装了 rsvg / inkscape / imagemagick 任一个即可
rsvg-convert -w 512 -h 512 职引-LOGO.svg -o 职引-LOGO-512.png
rsvg-convert -w 1200 -h 900 职引-会话背景.svg -o 职引-背景-1200x900.png
```

没装工具也没关系：用浏览器打开 SVG → 右键"另存为图片"，或直接截图后裁剪。
