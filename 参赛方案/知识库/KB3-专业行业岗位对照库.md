# KB3 · 专业-行业-岗位对照库

> 用途：「职引」岗位匹配与「专业适配度」判断的依据。
> 说明：学院名称取自大赛报名系统的 55 个参赛单位清单（与学校组织架构一致）。

---

## 一、使用说明

本库回答三个问题：
1. **我这个专业，能去哪些行业？**
2. **这些行业里有哪些典型岗位？**
3. **这些岗位要求什么技能？我该补什么？**

> ⚠️ 企业名称仅为**行业示例**，实际校招企业以当年就业网发布为准。
> 标注 ★ 的是**样板专业**（已做深，含岗位技能拆解）。

**专业适配度判断规则（供智能体使用）**

```
若 目标岗位 ∈ {工艺工程师, 研发工程师, 质检/分析工程师, EHS 工程师, 生产管理}
   且 专业 ∈ {化学工程与工艺, 应用化学, 制药工程, 材料类}
   → 专业对口度：高
   → 提示：突出化工原理/反应工程/分离工程等专业课基础，以及 Aspen、仪器操作等工具技能

若 目标岗位 ∈ {数据分析, 软件开发, 产品运营}
   且 专业 = 化学工程与工艺
   → 专业对口度：中（转行方向）
   → 提示：需用项目/实习证明跨领域能力，重点突出数据处理、编程、业务理解
```

**建议补充的经历（若简历中缺失）**
- 一段**完整的工艺模拟**（Aspen Plus 全流程，含物料衡算表）
- 一段**实验室项目**（说明实验设计方法 + 数据分析手段）
- 一段**仪器操作**经历（HPLC/GC 等，说明检测项目与规范）
- 一段**团队协作**经历（课程设计、大创、竞赛均可）

## 四、通用映射规则（智能体使用）

### 4.1 匹配度计算

```
岗位匹配度 = 专业相关度(40%) + 技能命中率(35%) + 地域/类型偏好(15%) + 经历相关度(10%)
```

| 维度 | 计算方式 |
| --- | --- |
| 专业相关度 | 按本库第二章/第三章的行业相关度映射 |
| 技能命中率 | 简历技能 ∩ 岗位必备技能 / 岗位必备技能 |
| 地域/类型偏好 | 是否满足用户提出的城市、实习/全职要求 |
| 经历相关度 | 简历中经历关键词与岗位职责的重合度 |

### 4.2 输出要求

对每个推荐岗位输出：
1. 岗位名称 + 企业类型 + 城市
2. **匹配度**（0–100，用进度条展示）
3. **匹配理由**（1–2 句，必须提到具体技能或专业对应关系）
4. **差距提示**（该岗位要求但简历中缺失的 1–2 项）
