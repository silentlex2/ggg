## 1. 为什么要扩充

原 KB4 共 65 条岗位，行业与技能写得很细，但**专业覆盖偏科**：化学工程与工艺 21 条、应用化学 8 条，
而英语 / 翻译、体育、法学、心理学、教育学、金融、统计这些专业几乎为零。
「职引」是给全校用的，重庆理工大学有 18 个教学单位，专业偏科意味着半个学校的学生问「有什么对口岗位」时，
检索只能给到化工、机械、计算机这几个方向的岗位。

本轮补 **15 条**，把所有教学单位都覆盖到，同时补上专业名称对照与城市字段约定两个附录，
让检索能识别「机械 / 机械类 / 机械工程」是同一个专业。

## 4. 怎么上传（控制台 UI，脚本够不到）

> 🔴 **前提事实（2026-10-20 实测）**：知识库只能通过控制台页面改。
> `/console/api/datasets` 对本账号返回 0 条，工作流里绑的 6 个 `dataset_id` 在
> `/console/api/datasets/{id}`、`.../documents`、`.../hit-testing` 上分别返回
> 404 `dataset_not_found`、400 `param_invalid`、400 `invalid dataset_id`（补横线后同样 404）。
> 运行时检索却是正常的——实测岗位分支命中 5 条、分数 0.87–1.00，来源 `KB4-岗位JD库（知识库版）(2).md`。
> 即：知识库由平台侧托管，**只能手工上传**。

步骤：

1. 登录 `https://aiagent.cqut.edu.cn:31134` → 进入「职引 · 校园就业智能体」→ **知识库** 页。
2. 找到岗位库（现在的文档是 `KB4-岗位JD库（知识库版）(2).md`）。
3. 上传 `KB4-岗位JD库（知识库版）-v2-扩充80.md`，分段方式选 **自定义 / 按 `##` 分段**，
   分段标识符填 `##`（与现有文档一致）。
4. 等索引完成（80 段 + 4 段附录），状态显示「可用」。
5. **先别删旧文档**：新文档索引完后，用下面的验证再决定是否删。

## 5. 上传后怎么验证

```
python 技术档案/kb_live_check.py       # 看岗位分支命中数与来源文档名
python 技术档案/run_all.py             # 五分支巡检 + 黄金集门禁
```

通过标准：

- `kb_live_check.py` 的 `retriever_resources` 里出现 **v2 扩充80** 的文档名，且命中 ≥3 条、分数 ≥0.85；
- `run_all.py` 的 `PATROL: 5/5`；黄金集 `SCORE ≥ 0.95`（E5 仍是已知红项，不算回退）。

不通过就删掉 v2 文档，旧文档一直在，检索会自然回到 65 条版本。
