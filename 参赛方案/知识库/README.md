## 二、上传配置参数（照着填）

### 2.1 非结构化知识库（KB1 / KB2 / KB3 / KB4-md / KB5）

| 参数 | 建议值 | 理由 |
| --- | --- | --- |
| 数据类型 | 非结构化数据 | 均为 Markdown 文档 |
| 分段方式 | **自定义** | 三个库都按 `##` 标题组织，按标题分段语义最完整 |
| 分段标识符 | `##` | 与文件结构对应 |
| 分段最大长度 | **800 tokens** | 单条岗位/单道题的长度量级 |
| 分段重叠长度 | **120 tokens（15%）** | 建议值的 10–25% 区间内 |
| 文本预处理 | 开启（合并连续空格/换行） | 去除 Markdown 排版噪声 |
| 解析方式 | 快速解析 | 均为纯文本文档，无需 OCR |
| Embedding 模型 | 平台内置默认模型 | — |

### 2.2 问答对知识库（KB6）

| 参数 | 建议值 |
| --- | --- |
| 数据类型 | 问答对 |
| 分段 | **单条即一段**（不要合并，否则会串题） |

> 上传前建议把 `**Q1：**` / `**A1：**` 拆成平台要求的「问题 / 答案」两列格式。

### 2.3 检索参数（在**大模型节点/知识库节点**里设置）

| 参数 | 建议值 | 理由 |
| --- | --- | --- |
| 检索方式 | **混合检索** | 兼顾关键词精确匹配与语义理解 |
| 权重 | 语义 0.6 / 全文 0.4 | 学生提问口语化，语义权重略高 |
| 最大召回片段数 | **5** | 默认 3 偏少，5 能覆盖更多依据 |
| 结果重排 | **开启** | 提升 Top 结果的准确性 |
| 相似度匹配值 | **0.45** | 略低于默认 0.5，避免"召回不到" |
| 引用与归属 | **开启** | 输出里显示来源，防幻觉、增强可信度 |

> ⚠️ 不同知识库可以设置不同参数：**岗位库**建议提高全文检索权重（岗位名/技能是关键词），
> **政策库**建议提高语义权重（学生问法多样）。

## 三、数据库节点配置（岗位库，进阶方案）

把 `KB4-岗位JD库.csv` 导入平台数据库后，在**数据库节点**中使用。

### 3.1 表结构（字段说明）

| 字段 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- |
| `id` | int | 主键 | 1 |

| `salary_range` | varchar | 薪资参考 | 8-12万/年 |
| `updated_at` | varchar | 更新时间 | 2026-09 |

### 3.2 自然语言转 SQL 的提示词建议

在数据库节点前加一个**大模型节点**做条件抽取，提示词：

```
你是查询条件抽取器。请从用户的话中抽取以下字段，输出严格的 JSON，不要任何解释：
{
  "city": "城市关键词（如 重庆/长寿/渝北），没有则空字符串",
  "job_type": "校招 或 实习，没有则空字符串",
  "major": "专业关键词，没有则空字符串",
  "skills": ["技能关键词数组，没有则空数组"],
  "industry": "行业关键词，没有则空字符串"
}
用户输入：{{query}}
```

> 然后把 JSON 里的非空字段拼成 SQL 的 `WHERE` 条件（技能字段用 `LIKE '%技能%'` 模糊匹配）。

### 3.3 匹配度打分（代码节点，Python）

```python
# 输入变量：user_skills（用户技能列表）、job_must_skills（岗位必备技能，分号分隔）
#          user_major（用户专业）、job_major_req（岗位专业要求）
# 输出变量：score（0-100）

def main(user_skills, job_must_skills, user_major, job_major_req):
    user_skills = [s.strip().lower() for s in (user_skills or [])]
    must = [s.strip().lower() for s in (job_must_skills or "").split(";") if s.strip()]

    # 技能命中率（35%）
    if must:
        hit = sum(1 for m in must if any(m in u or u in m for u in user_skills))
        skill_score = hit / len(must) * 100
    else:
        skill_score = 60

    # 专业相关度（40%）
    majors = [m.strip() for m in (job_major_req or "").split(";") if m.strip()]
    if not majors or "不限" in majors:
        major_score = 75
    elif any(user_major and (user_major in m or m in user_major) for m in majors):
        major_score = 100
    else:
        major_score = 55

    # 简化计算（地域与经历相关度由大模型节点补充）
    score = major_score * 0.4 + skill_score * 0.35 + 75 * 0.25
    return {"score": round(score)}
```

> 说明：地域与经历相关度难以用规则算，交由**下游大模型节点**在生成"匹配理由"时综合判断，
> 最终匹配度可取「规则分 × 0.6 + 大模型评分 × 0.4」。
