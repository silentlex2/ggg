# KB5 · 就业政策与流程库

> 用途：「职引」政策咨询模块的知识库。回答"怎么办事"类问题（三方协议、档案、报到证等）。
> 说明：本库为**通用政策框架**，具体以学校就业网与国家最新规定为准，回答时应提示"以官方最新通知为准"。

---

## 一、就业协议书（三方协议）

### 1.1 是什么

《全国普通高等学校毕业生就业协议书》，由**学生、学校、用人单位**三方签署，
用于确认就业意向、办理**报到证**与**户口档案**转移。一式三份，三方各执一份。

### 1.2 签署流程

```
学生领取协议 → 与用人单位协商填写 → 单位盖章 → 学生签字
   → 交回学校就业中心审核盖章 → 学校留存一份 → 学生与单位各留一份
```

### 1.3 关键注意事项

| 事项 | 说明 |
| --- | --- |
| **违约金条款** | 部分单位会约定违约金，**签字前务必确认金额**（常见 0–5000 元） |
| **报到期限** | 协议上会写明报到时间，逾期未报到可能被视为违约 |
| **试用期约定** | 试用期应写入协议或劳动合同，不得口头约定 |
| **补充条款** | 关于薪资、岗位、工作地点的口头承诺，**务必写入补充条款** |
| **考研/考公上岸** | 若同时考研，注意协议中的解约条款，部分单位接受"升学不视为违约" |

### 1.4 违约怎么办

1. 先与用人单位**书面沟通**，说明原因，争取**免除或减免违约金**
2. 取得单位出具的**解约函**（需盖章）
3. 携带解约函到学校就业中心办理**换发新协议**
4. 注意：**违约记录可能影响学校对该单位的后续招聘名额**，慎重决定

## 二、报到证

### 2.1 作用

- 证明毕业生属于**国家统招计划内**毕业生
- 办理**户口迁移**与**档案转递**的凭证
- 用人单位办理**入职手续**、**落户**的重要材料

### 2.2 办理与注意事项

| 事项 | 说明 |
| --- | --- |
| 签发时间 | 一般在毕业前由学校统一办理 |
| 抬头 | 必须与用人单位或人才市场名称**完全一致** |
| 有效期 | 通常为 **2 年**（择业期），逾期可能影响改派 |
| 改派 | 若更换单位，需在规定期限内办理改派手续 |
| 丢失 | 可申请补办，但流程较长，**务必妥善保管** |

> 📌 近年部分地区已推行"**报到证取消**"改革，具体以毕业当年政策为准。

## 三、档案（人事档案）

### 3.1 档案里有什么

高考材料、学籍卡、成绩单、毕业生登记表、体检表、奖惩材料、党团材料等。

### 3.2 毕业后档案去哪

| 去向 | 适用情况 |
| --- | --- |
| 用人单位 | 单位**有档案管理权限**（国企、事业单位、机关） |
| 单位所在地人才市场 | 单位无管理权限，委托人才市场托管 |
| 生源地人才市场 | 未就业、灵活就业、出国、考研未上岸 |
| 学校（暂存） | 部分学校可暂存 2 年，**到期必须转出** |

### 3.3 必须知道的坑

- ⚠️ **档案不能自己拿**：个人保管的档案会变成"死档"，人才市场不予接收
- ⚠️ **不能拆封**：档案袋封条拆开即失效
- ⚠️ **要及时确认接收**：转递后 1 个月内联系接收单位确认已收到
- ⚠️ 影响：考公、考编、职称评审、退休核算工龄**都要用档案**

## 四、户口迁移

- **入学时迁入学校集体户的**：毕业时需迁出，去向为工作地或生源地
- **未迁入户口的**：保持原户籍，一般无需处理
- 办理材料：报到证、毕业证、身份证、户口迁移证
- ⚠️ 部分城市（如重庆）已放开落户限制，具体咨询当地公安户政部门

## 五、劳动合同与试用期（入职必看）

### 5.1 法律要点

| 项目 | 规定 |
| --- | --- |
| 合同形式 | **必须书面**，用工之日起 **1 个月内**签订 |
| 试用期长度 | 合同 3 个月–1 年：试用期 ≤1 个月<br>1 年–3 年：≤2 个月<br>3 年以上/无固定期限：≤6 个月 |
| 试用期工资 | **不得低于**本单位相同岗位最低档工资或约定工资的 **80%**，且不低于当地最低工资 |
| 试用期解除 | 单位需**证明不符合录用条件**，不能随意辞退 |
| 社保 | **试用期也必须缴纳**，不缴属违法 |
| 违约金 | 仅限**服务期**与**竞业限制**两种情形，其他违约金条款无效 |

### 5.2 签约前必查

- [ ] 合同主体与面试单位**是否一致**（警惕外包/派遣）
- [ ] 薪资结构（基本工资 / 绩效 / 补贴）写清楚
- [ ] 工作地点、岗位名称明确
- [ ] 社保公积金缴纳基数与比例
- [ ] 是否有"竞业限制"条款（影响后续跳槽）

## 六、应届生身份

- **定义**：一般指毕业当年及择业期内（通常 2 年）未落实正式就业的毕业生
- **价值**：考公、考编、国企校招、部分城市落户**只认应届生**
- **如何保留**：
  - 不签劳动合同、不缴社保（部分认定标准）
  - 档案、户口保留在学校或生源地人才市场
- ⚠️ 各地认定标准不同，**务必提前咨询当地人社部门**

## 八、求职常见权益保护

- **招聘收费**：任何以"培训费""押金""服装费"名义收费的，**一律警惕**
- **扣押证件**：用人单位不得扣押身份证、毕业证原件
- **虚假招聘**：可通过学校就业中心、当地人社局核实企业资质
- **个人信息**：简历中避免填写身份证号、家庭住址等敏感信息

### 10.2 申领前的三个关键动作

1. **先办就业登记**：绝大多数补贴要求"先办理就业登记、连续参保满一定期限"才能申请，登记时要选择"高校毕业生"人员类别并上传毕业证。
2. **先缴后补**：社保类补贴一律"先缴后补"，不是入职即发。
3. **别重复申领**：同一人员同一类型补贴一般只享受一次；单位就业社保补贴与一次性吸纳就业补贴不重复享受。

### 10.3 官方办理渠道

- **线上**：渝快办 App / 小程序 →"渝悦·就业"应用；"渝职聘"平台；重庆市公共就业服务网
- **线下**：就业地或注册地街道（乡镇）公共就业创业服务机构、区县人力社保局
- **校内**：优先问学校招生就业处，通常会统一组织一次性求职补贴、见习基地推荐

### 10.4 常见误区

- 见习补贴**不是发给见习生本人**，而是补贴给见习基地，用于支付基本生活费与保险
- "离校 2 年内"从毕业当年 7 月 1 日起算，不是按自然年
- 断保离职后补贴停止发放；12 个县制造业补贴换企业需重新认定
